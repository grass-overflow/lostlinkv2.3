♻️ System Lifecycle

1. User Reports Lost Item + Image
2. AI Agent Scans & Extracts Features
3. TF-IDF + Embedding Search in Database
4. AI MATCH FOUND?
5. Instant Email & Call Alerts Sent
6. Claims Lifecycle: Verification & Recovery

Matching Logic: We use a hybrid approach. Text is matched using 1-3 Gram TF-IDF (word/char), while images are compared using MobileNetV2 feature vectors for similarity scoring. Premium users get Gemini-powered semantic reasoning.
